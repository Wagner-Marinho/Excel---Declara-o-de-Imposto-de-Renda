# Excel---Declara-o-de-Imposto-de-Renda
📑 Declaração de Imposto de Renda - Modelo de Coleta de Dados (DIO)
Este repositório/documento contém o resumo explicativo das informações, estrutura e finalidade da planilha DECLARAÇÃO DE IMPOSTO DE RENDA - DIO.xlsx, desenvolvida como um modelo (template) para coleta, organização e controle das informações necessárias para o preenchimento da Declaração de Ajuste Anual do Imposto de Renda Pessoa Física (IRPF).

📌 Visão Geral
A planilha funciona como um formulário padronizado de cadastro e consolidação financeira. Ela organiza os dados pessoais do titular, informações de contas bancárias, extratos de movimentação (entradas) e uma lista de instituições financeiras integradas via validação de dados.

🗂️ Estrutura das Abas
A planilha é composta por 4 abas (planilhas de trabalho):

1. Dados — Cadastro do Titular
Esta aba destina-se ao registro das informações pessoais e de contato do contribuinte:

Nome completo

CPF

Data de nascimento

Telefone/Contato

E-mail

Endereço residencial e CEP

Informações complementares

2. Informações — Dados Bancários e Patrimoniais
Aba voltada para o detalhamento das contas bancárias e saldos do titular:

Banco: Seleção da instituição financeira a partir de uma lista suspensa.

Saldo: Saldo da conta em 31 de dezembro do ano-exercício.

Anexo: Indicação de comprovantes ou informes de rendimentos associados.

3. Notas — Controle de Extratos e Rendimentos
Aba dedicada ao registro analítico de entradas e movimentações financeiras:

1 - EXTRATOS (Seção de Entradas):

Data: Data do recebimento/movimentação.

Categoria: Classificação do rendimento (ex.: Salário, Renda Variável, Prestação de Serviços, etc.).

Valor: Montante financeiro recebido.

4. Planilha1 — Tabela de Referência de Instituições Financeiras
Aba interna utilizada como base de dados para validação e seleção de instituições financeiras no formulário. Contém uma lista cadastrada com mais de 50 bancos e corretoras, incluindo:

Bancos Tradicionais: Banco do Brasil, Caixa Econômica Federal, Bradesco, Itaú Unibanco, Santander, Safra, Banrisul.

Bancos Digitais & Fintechs: Nubank, Banco Inter, C6 Bank, PicPay, PagBank, Stone, Neon.

Corretoras & Investimentos: XP Investimentos CCTVM S.A., BTG Pactual, Modal.

🛠️ Aplicação e Utilidade
Organização Pré-Declaração: Evita o esquecimento de contas ou fontes de rendimento no momento de preencher o programa da Receita Federal.

Padronização: Facilita a coleta de dados por escritórios de contabilidade ou consultores fiscais junto aos clientes.

Histórico Financeiro: Mantém o registro consolidado dos informes de rendimento e saldos bancários ano a ano.
